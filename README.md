# RiskFlow

**RiskFlow** ist eine Progressive Web App (PWA) zur Erstellung und Verwaltung von Gefährdungsbeurteilungen im Arbeitsschutz.

## 🎯 Features

- ✅ **Offline-funktionsfähig** – Arbeitet ohne Internetverbindung
- ✅ **Installierbar** – Als native App auf Smartphone/Tablet
- ✅ **Datenspeicherung** – Lokale Speicherung mit IndexedDB
- ✅ **Responsive Design** – Optimiert für alle Geräte
- ✅ **Modernes Frontend** – Vanilla JavaScript mit ES6+
- ✅ **Arbeitsschutz-fokussiert** – Professionelle Benutzeroberfläche

## 🚀 Live

**Verfügbar unter:** https://riskflow.pages.dev

## 📋 Funktionen

### Gefährdungsbeurteilungen
- Neue Beurteilungen erstellen und verwalten
- Gefährdungen dokumentieren und bewerten
- Maßnahmen zuweisen und verfolgen
- Offline-Zugriff auf alle Daten

### Risikobewertung
- Systematische Risikoanalyse
- Schweregrad und Häufigkeit bewerten
- Maßnahmen priorisieren
- Effektivität der Maßnahmen überprüfen

## 🛠️ Technologie

- **Framework:** Vite + Vanilla JavaScript (ES6+)
- **Offline:** Service Worker + IndexedDB
- **PWA:** Web App Manifest
- **Hosting:** Cloudflare Pages
- **Versionskontrolle:** Git + GitHub
